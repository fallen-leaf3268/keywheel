# 目标隔离的原始输入重放设计

## 目标

让按键轮盘通用兼容通过 Forge 原始键盘或鼠标事件触发的功能，同时保持现有玩家体验：短按、长按呼出轮盘、交换模式、功能锁定和保持长按均不改变，并且一次轮盘选择只触发选中的一个 `KeyMapping`。

## 兼容范围

支持通过正常 `KeyMapping` 注册、但在 `InputEvent.Key` 或对应鼠标输入事件中比较绑定键的功能。无需维护模组 ID、功能 ID 或兼容白名单。

不保证兼容完全绕过 `KeyMapping`、硬编码键码或直接轮询 GLFW 物理状态的实现，因为这类实现没有可用于识别目标功能的映射身份。

## 架构

新增目标隔离的合成输入事务。事务仅在客户端线程同步分发一次合成输入期间存在，包含选中的 `KeyMapping`、原始绑定键、输入类型和按下或释放阶段。

轮盘选择不再立刻修改 `clickCount` 和 `setDown`。它先记录待执行目标并关闭轮盘，再把执行任务排入 Minecraft 客户端任务队列。任务开始时创建事务，通过原版 `KeyboardHandler` 或 `MouseHandler` 重放输入，并在 `finally` 中清除事务。

事务期间，选中目标正常参与按键匹配；绑定到相同物理键的其他映射在 `getKey`、`matches`、`matchesMouse`、Forge 直接匹配、静态查找、`click` 和 `setDown` 等入口均被隔离。KeyWheel 自身的物理键拦截对当前合成事件临时放行，且重入保护阻止它再次启动轮盘流程。

## 组件职责

### 合成输入上下文

保存当前目标与输入阶段，提供目标身份判断、同键映射屏蔽、合成事件识别和可靠清理。上下文只允许在客户端线程使用，不跨线程传播。

### 延迟执行队列

接收轮盘选中的目标，在轮盘完全关闭后执行。若玩家离开世界、目标解绑或目标已经不在当前按键列表中，则取消任务并清理状态。

### 原版输入调用器

键盘目标通过原版键盘处理入口重放，鼠标目标通过原版鼠标处理入口重放。只支持轮盘当前已经支持的 `KEYSYM` 和 `MOUSE` 类型；无法重放的类型退回现有 `ActionExecutor`。

### 映射隔离层

复用并扩展现有锁定与冲突 Mixin。隔离只对当前合成事务和相同物理键生效，不改变映射配置、注册表或缓存，不临时改绑按键。

## 输入流程

1. 玩家长按物理键并打开轮盘。
2. 玩家选中目标功能。
3. KeyWheel 记录目标、绑定键和保持状态。
4. 轮盘关闭并恢复正常游戏界面。
5. 客户端任务开始目标事务。
6. 通过原版输入处理器重放一次按下事件。
7. Forge 原始事件监听器与普通 `KeyMapping` 消费者均收到与真实输入一致的处理机会，但只有目标映射能够匹配。
8. 普通功能在下一客户端阶段重放释放；保持长按功能保留按下状态。
9. 事务在每次同步事件分发结束后立即清除。

## 保持长按与释放

保持长按继续沿用现有配置。目标收到合成按下后进入保持集合，`KeyMapping.setAll()` 不得覆盖其状态。下一次真实键盘或鼠标按下、配置关闭、成员移除或世界不可用时，先结束保持状态，再以新的短事务重放目标释放，最后继续处理玩家的新输入。

原始事件型的一次性功能通常只处理按下事件；它仍只执行一次。需要持续读取 `KeyMapping.isDown()` 的功能继续获得现有保持语义。

## 锁定、短按与交换模式

功能锁定继续阻止轮盘外的目标按下，合成事务只放行当前选中目标。短按路径不使用合成重放，保持当前主功能与普通冲突处理。交换模式只修改成员与主功能，不执行目标，因此不创建事务。

## 故障处理

所有事务使用 `try/finally` 清理。原版调用器不可用、键类型不支持或任务执行异常时，清除事务并退回当前 `ActionExecutor`，避免功能完全失效。合成事件引发的新界面不会被轮盘关闭逻辑覆盖，因为重放发生在轮盘关闭之后。

事务是短生命周期状态，不写入配置；客户端重启后不存在残留。该机制不新增网络协议，模组保持纯客户端属性。

## 性能

正常游戏与物理输入只增加一次快速的“是否存在合成事务”判断。映射遍历和隔离只发生在玩家完成轮盘选择时，不增加每 Tick 扫描，也不修改全局按键注册表。

## 测试

- 选中目标只收到一次按下，不产生双触发。
- 同物理键的其他映射在合成事务中无法匹配、点击或进入按下状态。
- 原始键盘和鼠标事件均在轮盘关闭后分发。
- 普通 `consumeClick`、`isDown` 和 Forge 原始事件监听方式均可触发。
- 短按、交换模式、功能锁定和保持长按保持现有回归结果。
- 普通释放、保持释放、配置清理和世界退出不会留下按下状态。
- 事务中抛出异常后上下文必定清空，后续真实输入不受影响。
- 产物中不包含 Passive Skill Tree 或其他第三方模组的专用标识。
- 使用 Passive Skill Tree 的 `key.display_skill_tree` 进行最终实机验证：轮盘选择打开技能树，同键其他功能不触发。

## 验收标准

玩家操作方式与当前版本一致；此前只能通过真实短按触发的正常 `KeyMapping` 原始事件功能可以从轮盘触发；一次选择严格只执行目标功能；客户端能够连接未安装 KeyWheel 的服务器；完整回归测试和构建通过。
